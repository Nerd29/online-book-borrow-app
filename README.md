# 📚 BookBridge

> A modern, full-stack online book borrowing platform connecting readers and empowering seamless book discovery and user management.

🌐 **Live Demo:** [https://online-book-borrow-app.vercel.app](https://online-book-borrow-app.vercel.app)

---

## 📖 Purpose

**BookBridge** was designed to streamline book borrowing and discovery. It provides a platform where users can explore featured titles, manage their reading lists, update their personal user profiles, and interact with dynamic library collections with an intuitive user experience.

---

## ✨ Key Features

* **🔐 Authentication & Session Management:** Secure sign-in, registration, and user session persistence powered by Better-Auth.
* **👤 User Profile Management:** Dynamic user profile page allowing users to update their personal information and avatar on the fly.
* **📱 Fully Responsive Design:** Mobile-first, adaptive navigation layout featuring a modern drawer menu for smaller screens.
* **🌙 Dark & Light Mode Toggle:** Full theme customizability supporting dark and light mode preferences.
* **📚 Interactive Book Explorer:** Dedicated views for browsing all available collections and featured book categories.
* **⚡ Modern UI & Animations:** Smooth animations driven by `@lottiefiles/dotlottie-react` and dynamic backdrop blur effects.
